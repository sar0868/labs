# 8.10. Домашнее задание - Массивы

**Нужно решить набор упражнений и для каждого из них создать отдельный shell скрипт и отправить PR на проверку:**

## Упражнение 1: День недели

Напиши сценарий оболочки, который использует массив для хранения названий семи дней по-английски и выводит его на печать.
Подсказка: используй массив для хранения названий семи дней: Monday, Tuesday, Wednesday, Thursday, Friday, Saturday, Sunday.

---

## Упражнение 2: Выбери день

Напиши сценарий оболочки, который попросит ввести номер дня на неделе и вывести на печать его название.
Подсказка: выведи на печать определенный элемент массива, соответствующий нужному номеру дня. Номер можно запросить через read в переменную, а делее обратиться к индексу массива через эту переменную.

---

## Упражнение 3: Сколько дней в неделе

Напиши скрипт оболочки, который выводит количество дней в неделе из упражнения 1.
Подсказка: используй echo ${#week[@]}, где week — имя массива.

---

## Упражнение 4: Поменяй дни

Напиши скрипт оболочки, чтобы поменять среду и пятницу местами относительно первоначального порядка, как определили в упражнении 1.
Подсказка: используй временную переменную для хранения значения одного из элементов перед их заменой.

---

## Упражнение 5: Добавь еще один день

Напиши скрипт оболочки, чтобы добавить 8-й день в массив week, описанный в упражнении 1. Он должен быть последним (т.е. восьмым) и иметь значение "Earthsday".

Подсказка: используй week+=("Earthsday"), чтобы добавить элемент в конец массива.
