# 3.8. Домашнее задание - Переменные

Нужно решить набор упражнений и для каждого из них создать отдельный shell скрипт и отправить PR на проверку:

## Упражнение 1: Имя скрипта

Напиши скрипт оболочки, который показывает имя этого скрипта.
Подсказка: используй $0 чтобы получить имя скрипта.

---

## Упражнение 2: Вывод наоборот

Напиши скрипт оболочки, который получает три аргумента и печатает их в обратоно порядке в одной строке.
Подсказка: здесь не требуется сложная логика, просто выведи позиционные параметры в нужном порядке.

---

## Упражнение 3: Отображение ввода

Напиши скрипт оболочки, который запрашивает сегодняшний день недели и выводит его.
Подсказка: используй команду echo и read.

---

## Упражнение 4: Сложное отображение

Измени скрипт оболочки, чтобы после для недели он запрашивал число и выводил в одной строке с днем недели.
Подсказка: используй дополнительную команду read для сохранения целого числа в переменной, и добавть вывод второй переменной в команду echo

---

## Упражнение 5: Определи константу

Напиши скрипт, в котором объявляется переменная для числа числа Пи. Далее выводится его значение. В скрипте убедись, что значение переменной нельзя изменить.
Подсказка: используй команду readonly для сохранения значения Пи в виде строки "3.14".

---

## Упражнение 6: Вывод даты

Напиши скрипт оболочки, который сохраняет текущую дату в переменной и выводит ее.
Подсказка: используй команду date, чтобы сохранить вывод в переменной и вывести ее с помощью echo.

---

## Упражнение 7: Все вместе

Напиши скрипт оболочки, который получает и выводит все данные для упражнений 1, 2 и 4. Выведи все ответы в отдельной строке с заданным форматированием.

Формат должен быть таким:

```
Привет, какой сегодня день недели?
tuesday
Уже tuesday
Какое сегодня число?
1
Не думал что tuesday будет 1 числа
Я считаю что сегодня Tue Oct  1 10:59:01 UTC 2024
```
