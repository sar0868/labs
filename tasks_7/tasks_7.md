## Упражнение 1: Построчный ввод

Дан однострочный код с циклом, который будет построчно читать стандартный поток ввода и показывать его на экране строка за строкой.

```
while read line; do ((++i)); echo "line$i,$line,"; done
```

Измени команду так, чтобы данные были получены из файла /etc/os-release.
Подсказка: Добавь в конец инструкцию перенаправления в stdin из файла /etc/os-release

## Упражнение 2: Построчный вывод

Команда из задания 1. Добавь конвейер, в котором вывод будет делиться на два аргумента по полю запятой и выводиться на экран.

Подсказка: Ты можешь использовать xargs с указанием количества аргументов (флаг -n) и указанием разделителя (флаг -d)

## Упражнение 3: Файлы из аргументов

У нас прежний однострочник:

```
while read line; do ((++i)); echo "line$i,$line,"; done < /etc/os-release | xargs -n 2 -d ','
```

Измени команду, которую исполняет xargs, так, чтобы в текущей директории создавался файл с именем, полученным из первого аргумента и контентом из второго.

Имей в виду, что первый аргумент после содержит скрытые символы и его стоит почистить, прежде чем использовать в виде имени для файла.

Это можно сделать командой `tr -cd "[:print:]\n"`. Также я советую запускать в команде xargs вместо echo дополнительную оболочку, в которой произвести очистку и сформировать файлы.

Подсказка: запусти в xargs дополнительную оболочку: `sh -c '<команда1; команда2;>'`. Внутри этих команд сделай очистку и команду записи в файл.
