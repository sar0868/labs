# 9.8. Домашнее задание - Текстовые утилиты

Нужно решить набор упражнений и для каждого из них создать отдельный shell скрипт и отправить PR на проверку:

## Упражнение 1: Автоматизация управления пользователями на серверах

Напишите скрипт bash, который автоматизирует весь процесс создания пользователя на нескольких серверах.

Советы: Сначала создай текстовый файл, который включает все имена хостов или IP-адреса серверов, на которые требуется добавить пользователя.

Например, создай файл servers.txt, который включает имена трех разных серверов:
cat servers.txt

```
host1
host2
host3
```

Это имена серверов, а IP-адреса, как предполагается, уже включены в файл /etc/hosts, так что можно подключиться по SSH к любому из этих серверов.

Ты также можешь использовать файл конфигурации SSH.

Сначала скрипт попросит вас ввести имя пользователя и идентификатор пользователя, которого вы хотите добавить; затем он выполнит цикл и
подключится ко всем серверам в файле servers.txt через SSH и добавит запрошенного пользователя.

## Упражнение 2: Автоматизация резервного копирования на отдельный сервер

Напиши автоматизированный скрипт для резервного копирования архивов файлов на отдельный сервер.

Советы: создай массив с именем backup_dirs, в котором будут храниться все имена каталогов, которые мы хотим резервировать. Это значение скрипт должен получать из аргументов.

Затем создай три другие переменные:

- dest_dir для указания каталога назначения резервной копии.
- dest_server для указания сервера назначения резервной копии.
- backup_time для указания даты резервной копии.

Далее для всех каталогов в массиве backup_dirs создай сжатый в gzip tar-архив в размещении /tmp, а затем используй команду scp для отправки резервной копии на сервер хранения.

После удали временный архив из /tmp.

## Упражнение 3: Автоматизация мониторинга доступного дискового пространства

Используй команды df , tail , awk и cut, чтобы получить процент использования диска своей системы и проверить, больше ли он или равен 90%.

Советы: сначала создай массив filesystems с прописаными значениями, содержащий все файловые системы, которые требуется отслеживать.

Затем для каждой файловой системы получи процент использования с помощью указанных команд и проверь, он больше или равен 90%. Если использование превышает 90%, должен быть создан файл /alert.txt с сообщением, что файловая система исчерпывает место.
