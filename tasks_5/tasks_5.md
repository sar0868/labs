# 5.9. Домашнее задание - Циклы

**Нужно решить набор упражнений и для каждого из них создать отдельный shell скрипт и отправить PR на проверку:**

## Упражнение 1: Зацикленное сообщение

Создай цикл for для отображения сообщения 10 раз.

Подсказка: используй echo для вывода сообщения в цикле for.

## Упражнение 2: Выведи содержимое каталога

Выведи все файлы и каталоги, которые существуют в директории /var/var.

Подсказка: используй /var/\* в качестве диапазона цикла for

---

## Упражнение 3: Числа, кратные трем

Используй цикл while, чтобы вывести первые десять чисел, кратные трём.

Подсказка: сначала инициализируй переменную значением 11. После этого цикл while будет выполняться до тех пор, пока он меньше или равен 10. Внутри тела цикла while команда echo может вывести значение переменной, умноженное на 3, а затем увеличить это значение на 1, чтобы использовать его в следующей итерации.

---

## Упражнение 4: Кратные трём с циклом until

Используй цикл until, чтобы вывести первые десять чисел, кратные трём.

Подсказка: цикл until будет выполняться до тех пор, пока условие проверки ложно.
Отрицательная версия предыдущего условия [ $num -le 10 ] будет [ $num -gt 10 ]
